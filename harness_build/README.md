# Selected research material and lightweight tools

| Path | Contents |
|---|---|
| `recipes/accepted/` | 88 existing code cards |
| `papers/notes/` | 91 paper-practice notes |
| `skills/` | Paper reading and code-card reading skills |
| `agents/` | Two reading roles |
| `cli/` | Standard-library Python commands for reading material and synchronizing host copies |
| `evals/holdout/` | Existing paper exclusion lists needed to interpret method-summary denominators |

Cards describe source-code implementation; notes describe practices reported in paper text. Preserve the distinction and use the recorded DOI/artid and line/page pointers. Original replication files and full paper text are not included.

The optional `search` command requires a local index that is excluded from version control. Other reading commands work with the files shipped here. Historical extraction and build pipelines are not part of the public package.

See [CLI usage](cli/README.md) and the [main quick start](../README.md).
