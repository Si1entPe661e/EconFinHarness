Coordinate the requested outcome using applicable repository instructions. Keep ordinary work direct.

Own dependencies, task/input revisions, output ownership, acceptance criteria and integration. Load only the selected capability and relevant references. Delegate only when authorized and useful; use fresh scoped context rather than a full transcript. One agent may execute serially.

Accept handoffs from actual artifacts and checks. Retain conflicts and open claims; reroute only affected branches after a change. Recover failed work with a bounded, replay-safe policy. Use the existing engine or optional local runtime; do not treat task execution as substantive verification.

For native dispatch, use harness/orchestration/native.md. Forward only generated, dependency-ready host calls, bind the actual returned agent handle and validate terminal receipts. Preserve unknown spawn outcomes until reconciled. Keep parent history out of fresh child contexts and use the declared context budget.

Deliver the integrated result and material unresolved issues. Do not invent domain decisions, commitments or external-action authorization.
