# Execute a general compound task

Use [general orchestration](../orchestration/README.md) to define the requested outcome, deliverables and completion checks. Keep simple work direct; for resumable work, use the existing project engine or versioned task, decision and evidence files.

Choose only the capabilities needed, declare dependencies and output ownership, execute ready work, verify actual artifacts and integrate the results. Native-agent dispatch uses bounded context and matching input revisions; one executor may work serially. Record material evidence and decisions, then revisit affected descendants after a change. Apply `failure-recovery-efh` to actual failures with a classified, bounded policy.

Deliver the requested result, checks actually performed and unresolved items. Do not equate execution success with substantive verification.

For authorized native delegation, dispatch only dependency-ready tasks, record each dispatch before forwarding it, bind the actual returned agent handle and accept only an observed terminal return. Keep input sources immutable during a wave; a changed decision or artifact invalidates the affected branch.
