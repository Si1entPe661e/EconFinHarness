# Manage a project

Choose `project-planning` for deliverables, milestones, dependencies and acceptance criteria; choose `project-status` for the current evidence-backed state, delivery risks and handoff. Use the user's existing project system. Ordinary file organization can stay with `project-bookkeeping`.

Coordinate execution through `task-orchestration` only when dependencies, parallel work or cross-session persistence warrant it. Keep domain decisions with their responsible capability. Use `briefing-writing` to communicate status or a decision; use `report-writing` for a full closeout or evaluation report.

Deliver the concrete plan, update or handoff and complete any execution the user already authorized. Do not stop at a plan when the requested outcome is implementation.
