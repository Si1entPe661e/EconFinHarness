# Manage a project

Choose `project-planning-efh` for deliverables, milestones, dependencies and acceptance criteria; choose `project-status-efh` for the current evidence-backed state, delivery risks and handoff. Use the user's existing project system. Ordinary file organization can stay with `project-bookkeeping-efh`.

Coordinate execution through `task-orchestration-efh` only when dependencies, parallel work or cross-session persistence warrant it. Keep domain decisions with their responsible capability. Use `briefing-writing-efh` to communicate status or a decision; use `report-writing-efh` for a full closeout or evaluation report.

Deliver the concrete plan, update or handoff and complete any execution the user already authorized. Do not stop at a plan when the requested outcome is implementation.
