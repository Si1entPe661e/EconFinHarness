# Write an evidence-based report

Use `report-writing` for the audience, purpose and selected report mode. Read the supplied sources/results, separate facts from interpretation and recommendations, and retain uncertainty and counterevidence. Use `evidence-tracking` for material claims that span sources or revisions.

Draft the requested report, check its substantive support, then inspect the chosen document format. Route missing facts or conflicting results to the responsible task while completing supported sections. Load formatting tools only for the requested medium. A writing task does not authorize new estimation or external distribution.
