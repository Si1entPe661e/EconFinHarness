# Annotate research code

Use `code-annotation` and the relevant method guidance from the [composition guide](../skill-composition.md).

Read the requested code and add useful English comments on variables, timing, model choices, assumptions and error-prone operations. Preserve executable behavior and inspect the diff. Raise logic problems as separate findings rather than changing the design through comments.

Deliver the requested patch, annotated copy or sidecar. The current agent may perform the `explainer` responsibility.
