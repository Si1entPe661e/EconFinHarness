# Maintain project progress

Use `project-status` to inspect actual work, artifacts, checks and dependencies. Use the existing project system or optional durable checkpoints. Apply [general orchestration](../orchestration/README.md) for affected branches and handoffs; research-specific dependencies remain in the [composition guide](../skill-composition.md).

State completed work, output locations, gaps and the next useful step. Outputs needing regeneration after source or decision changes remain unfinished. Existing scripts or proposed work are not evidence that a task ran.

Deliver a progress explanation or update an existing project note. The current agent may handle the `project-manager` responsibility.
