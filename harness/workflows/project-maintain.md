# Maintain research progress

Use `project-bookkeeping` to inspect actual work, scripts and outputs. Update affected method, sample, estimation/inference, presentation and writing steps through the [composition guide](../skill-composition.md).

State completed work, output locations, gaps and the next useful step. Outputs needing regeneration after sample or inference changes remain unfinished. Existing scripts or proposed work are not evidence that an analysis ran.

Deliver a progress explanation or update an existing project note. The current agent may handle the `project-manager` responsibility.
