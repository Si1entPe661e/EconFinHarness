# Explain code, research or progress

Use `research-explanation` and read only the method, sample, inference or presentation skills needed through the [composition guide](../skill-composition.md).

Explain purpose, inputs, operations, result meaning and uncertainty using actual files. Clarify choices such as fixed effects versus clustering, and causal estimands versus prediction targets. Report progress from actual work and available outputs.

Deliver an explanation at the appropriate level; save Markdown when useful. An explanation alone does not require rerunning unrelated analyses.
