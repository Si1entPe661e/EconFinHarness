# Plan project work

Use `project-planning-efh` for concrete deliverables, milestones, ownership, dependencies and acceptance criteria. Use [general orchestration](../orchestration/README.md) when executing the plan requires coordination. Research analyses then use the [composition guide](../skill-composition.md) for domain-specific dependencies.

List actual work, responsibilities, input locations and missing material. Keep domain choices with the relevant capability and coordination with the planner/orchestrator. One agent may handle several responsibilities. Link to the selected execution or writing workflow as needed.

Deliver a concise plan using existing formats. Small tasks can be completed directly.
