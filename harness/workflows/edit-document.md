# Revise an existing document

Use `document-editing` for the requested revision level. Preserve factual meaning, qualifications, citations and commitments. Resolve source-based corrections where possible and flag unsupported claims. Use `academic-writing` only when manuscript-specific argument conventions are relevant.

Deliver the actual revision, inspect the requested format and explain material changes. Structural revision, copyediting and substantive fact-checking are different responsibilities; combine only those the task needs.
