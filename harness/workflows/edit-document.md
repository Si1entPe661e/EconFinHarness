# Revise an existing document

Use `document-editing-efh` for the requested revision level. Preserve factual meaning, qualifications, citations and commitments. Resolve source-based corrections where possible and flag unsupported claims. Use `academic-writing-efh` only when manuscript-specific argument conventions are relevant.

Finish with the [revise module](revise-writing.md) unless its skip conditions apply; copyediting and proofreading skip it. Deliver the actual revision, inspect the requested format and explain material changes. Structural revision, copyediting and substantive fact-checking are different responsibilities; combine only those the task needs.
