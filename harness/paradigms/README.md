# Method materials

Read existing method materials directly:

- `recommendations.md`: conditional methodological advice, exceptions and literature references.
- `observed.md` / `observed.json`: practices recorded in code cards.
- `reported.md` / `reported.json`: practices recorded in paper-practice notes.

Counts refer to papers. Unknown means insufficient recorded information. A common practice does not automatically become a recommendation. Compare paper statements and code observations where both are available.
