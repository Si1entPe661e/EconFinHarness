# Structural estimation commands

## R: binary choice with a price coefficient constrained negative

df contains choice (0/1), observed price and quality. Utility difference is alpha - exp(log_price_sensitivity)*price + quality_coefficient*quality + logistic error; error scale is normalized to one. This is a simple structural choice model conditional on exogenous observed attributes, not a repair for endogenous prices.

~~~r
d <- df[complete.cases(df[, c("choice", "price", "quality")]), ]
stopifnot(all(d$choice %in% c(0, 1)))
nll <- function(theta) {
  eta <- theta[1] - exp(theta[2]) * d$price + theta[3] * d$quality
  sum(pmax(eta, 0) + log1p(exp(-abs(eta))) - d$choice * eta)
}
starts <- list(c(0, 0, 0), c(1, -1, 1), c(-1, 1, -1))
fits <- lapply(starts, function(start) {
  optim(start, nll, method = "BFGS", hessian = TRUE,
        control = list(maxit = 2000, reltol = 1e-10))
})
ok <- vapply(fits, function(f) f$convergence == 0 && is.finite(f$value), logical(1))
stopifnot(any(ok))
best <- fits[ok][[which.min(vapply(fits[ok], function(f) f$value, numeric(1)))]]
print(best$par)
print(best$value)
print(c(price_coefficient = -exp(best$par[2])))
print(eigen(best$hessian, symmetric = TRUE)$values)
~~~

Only under a correctly specified independent likelihood with an interior identified solution can inverse-Hessian covariance be used directly. Transform uncertainty with the delta method or full refitting when reporting the price coefficient. Clustering or preliminary-stage uncertainty needs appropriate score covariance or resampling.

## MATLAB: simulated likelihood with supplied economic model functions

f_lik is the model-specific negative log likelihood; H_simulacion, type_simulacion and ftype_simulacion are fixed simulated inputs generated by the supplied model. They are required inputs, not built-in MATLAB objects.

~~~matlab
start = [10, 35, 35, 5];
options = optimset('MaxIter', 2000, 'MaxFunEvals', 20000, ...
                   'TolFun', 1e-8, 'TolX', 1e-8, 'Algorithm', 'quasi-newton');
[theta, value, exitflag, output, gradient, hessian] = fminunc( ...
    @(p) f_lik(p, H_simulacion, type_simulacion, ftype_simulacion), ...
    start, options);
disp(theta)
disp(exitflag)
disp(norm(gradient))
~~~

This requires MATLAB's Optimization Toolbox and the model's f_lik implementation. Evaluate additional starts and simulation draws before using the solution for counterfactuals.

## R: simulated moments for an isoelastic hours model

df contains positive hours and wage. The maintained model is hours = exp(alpha) * wage^beta * exp(sigma*epsilon), with epsilon standard normal independent of wage. A labor-supply elasticity interpretation additionally requires the economic model to support this equation; observed wage endogeneity cannot be ignored.

The moments are mean hours, mean hours times log wage, and mean squared hours. This illustrates fixed-draw SMM with diagonal moment scaling.

~~~r
d <- df[complete.cases(df[, c("hours", "wage")]), ]
stopifnot(all(d$hours > 0), all(d$wage > 0))
log_wage <- log(d$wage)
target <- c(mean(d$hours), mean(d$hours * log_wage), mean(d$hours^2))
scale <- pmax(abs(target), 1e-3)
set.seed(12345)
draws <- matrix(rnorm(nrow(d) * 200L), nrow = nrow(d))
simulate_moments <- function(theta) {
  simulated <- exp(theta[1] + theta[2] * log_wage + exp(theta[3]) * draws)
  c(mean(simulated), mean(simulated * log_wage), mean(simulated^2))
}
objective <- function(theta) {
  predicted <- simulate_moments(theta)
  if (any(!is.finite(predicted))) return(1e100)
  sum(((predicted - target) / scale)^2)
}
initial_fit <- lm(log(hours) ~ log(wage), data = d)
start <- c(coef(initial_fit), log(max(summary(initial_fit)$sigma, 1e-3)))
smm <- optim(start, objective, method = "BFGS",
             control = list(maxit = 2000, reltol = 1e-10))
print(smm$convergence)
print(c(alpha = smm$par[1], beta = smm$par[2], sigma = exp(smm$par[3])))
print(rbind(observed = target, simulated = simulate_moments(smm$par)))
~~~

Use multiple starts and more simulation draws to assess numerical stability. Simulation noise, sampling dependence and any preliminary estimated inputs must enter uncertainty; an optimizer's objective value alone does not provide parameter SE.
