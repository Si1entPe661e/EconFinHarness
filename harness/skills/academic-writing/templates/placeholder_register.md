# Placeholder register

Delivered with every draft that contains open items. The marker in the draft has the fixed form:

`[TODO: <what is missing> | owner: <role> | blocks: <claim id>]`

- draft id / file:
- compiled at (UTC):
- number of open placeholders:

| marker id | location (section, paragraph) | what is missing | why it cannot be filled now | owner role | blocked claim ids | needed before | status |
|---|---|---|---|---|---|---|---|
| P1 | | | | | | | open |
| P2 | | | | | | | open |

## Rules

- A placeholder is never replaced by an estimated or plausible value.
- A draft may be delivered with placeholders. It may not be delivered with unmarked gaps.
- Removing a placeholder requires the actual source that supplied the missing information.
- If a placeholder is removed because the claim was dropped, record that the claim was dropped rather than deleting the row.
